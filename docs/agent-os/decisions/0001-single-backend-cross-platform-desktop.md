# ADR-0001: один Hermes backend, два Desktop-клиента

- **Статус:** принято
- **Дата:** 2026-07-14

## Решение

Hermes backend разворачивается и остаётся единым на Mac mini. Клиенты Hermes Desktop для macOS и Windows подключаются к этому backend. Они не создают независимые профили, память или базы сессий.

## Причина

Вадим хочет пользоваться тем же Ray, Радиком и Дворецким на Mac и Windows, с одинаковым интерфейсом и сохранённым контекстом. Дублирование `HERMES_HOME`, SQLite-сессий, профилей и секретов на Windows создаст два расходящихся состояния и не допускается.

## Последствия

- Windows — основной интерфейс для проектной работы.
- Mac mini — постоянный backend, gateway и системный контур.
- Изменения Hermes Desktop собираются из одного исходного кода в `agent-os` для обеих платформ.
- Секреты, runtime-память и сессии остаются вне Git.
