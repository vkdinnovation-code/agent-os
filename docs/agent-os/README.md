# Agent OS

`agent-os` — единый приватный репозиторий Вадима для изменённого исходного кода Hermes Desktop и системной документации.

В корне лежит полный исходный код Hermes Agent. Наши документы находятся в `docs/agent-os/`.

## Принцип

Один Hermes backend на Mac mini хранит профили, память, сессии и интеграции. Клиенты Hermes Desktop на macOS и Windows подключаются к этому backend и работают с теми же агентами.

## Контуры

- **Радик** — Hermes, Mac mini, gateway, WebUI, профили, интеграции и восстановление.
- **Дворецкий** — личный контур: быт, рецепты, питомцы, огород и личная wiki.
- **Ray** — проектный директор и продуктовый контур; основной код исполняется на Windows.

## Обновления

Оригинальный `NousResearch/hermes-agent` используется как внешний источник обновлений. Наши изменения Desktop сохраняются в этом репозитории и проверяются на macOS и Windows перед выпуском.

Секреты, токены, OAuth, рабочие памяти и базы сессий в Git не хранятся.
